# Кофейня «Зерно» — мобильная адаптация

Откройте `index.html` в браузере. Адаптивные стили добавлены в конец `css/style.css` внутри медиазапросов для экранов до 768 px и 400 px.

## Что изменено
- Шапка и ссылки меню расположены столбиком.
- Уменьшены заголовок и отступы первого экрана.
- Кнопка растягивается на ширину контента.
- Карточки меню расположены в один столбец.
- Блок «О нас» и подвал расположены вертикально.
- Десктопные правила вне медиазапросов сохранены.

## Публикация на GitHub
Создайте публичный репозиторий, загрузите содержимое этой папки целиком (файлы `index.html`, `css/`, `img/` и дополнительные файлы), затем отправьте преподавателю ссылку на репозиторий.
